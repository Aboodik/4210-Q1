Stack Buffer Overflow Explorer

Type an input string and watch strcpy() copy it byte-by-byte into a fixed-size buffer. When the input is longer than the buffer, the extra bytes spill into adjacent stack memory — the saved frame pointer and the return address.

Attacker input

hello (safe) 12× A (overflow) reach return addr

Vulnerable code


        

          Why this is unsafe: strcpy copies until it hits a null byte, with no idea how big buffer is. The compiler lays locals out at lower addresses than the saved frame pointer and return address, and the copy writes toward higher addresses — so an over-long string marches straight up into the saved state of the caller.
